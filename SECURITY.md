# Security Policy

## Supported Versions

The versions of the project that are supported for security updates are:

| Version | Supported          |
| ------- | ------------------ |
| <0.9.0  |         :x:        |
| 1.0.0 + | :heavy_check_mark: |


## Reporting a Vulnerability

If there is a security vulnerability, please open an issue and have the title begin with [SECURITY]

> [!WARNING]
> If you do not mark it as [SECURITY], I may skip over it.
